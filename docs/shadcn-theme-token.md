> 参考链接 https://ui.shadcn.com/docs/theming#theme-tokens

| Token                                | 核心语义                  | 最典型场景                          | 可以理解成                |
| ------------------------------------ | ------------------------- | ----------------------------------- | ------------------------- |
| `background` / `foreground`          | 页面基础底色 / 默认内容色 | App 页面、正文                      | **整个画布**              |
| `card` / `card-foreground`           | 独立、抬升的内容容器      | Card、Dashboard Panel               | **静态容器**              |
| `popover` / `popover-foreground`     | 浮在页面上方的临时容器    | Dropdown、Popover、Context Menu     | **浮层容器**              |
| `primary` / `primary-foreground`     | 最高强调级别              | 主按钮、核心 CTA、重要选中态        | **我要你注意这里**        |
| `secondary` / `secondary-foreground` | 次一级填充元素            | 次按钮、次要 Badge                  | **有强调，但不是主角**    |
| `muted` / `muted-foreground`         | 弱化内容                  | 描述、placeholder、helper text      | **降低视觉噪音**          |
| `accent` / `accent-foreground`       | 交互状态强调              | hover、menu selected、ghost hover   | **鼠标经过 / 当前交互项** |
| `destructive`                        | 危险 / 错误               | 删除、移除、invalid                 | **危险操作**              |
| `border`                             | 普通边界                  | Card、Table、Separator              | **结构边界**              |
| `input`                              | 表单控件边界/表面         | Input、Textarea、Select             | **表单边界**              |
| `ring`                               | focus 状态                | 键盘焦点、Input focus、Button focus | **焦点提示**              |
| `chart-1 … 5`                        | 数据可视化色板            | Bar / Line / Pie Chart              | **图表序列色**            |
| `sidebar*`                           | Sidebar 独立主题体系      | 左侧导航                            | **侧栏的小型主题系统**    |
| `radius`                             | 全局圆角基准              | Button、Card、Popover 等            | **形状风格基准**          |
